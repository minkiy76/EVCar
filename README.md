##2026.04.08 Technical Decision

< #1. User 테이블 네이밍 유지 및 리팩토링 계획 >

초기 설계 단계에서 사용자 정보를 관리하는 테이블명을 **`user`** 로 정의하였다.<br>
프로젝트 진행 과정에서 **`user`** 는 데이터베이스 예약어와의 충돌 가능성이 있으며,<br> 
의미가 포괄적이어서 **실무에서는 명확한 네이밍으로 권장되지 않는다는 점을 확인** 하였다.<br>

현재 프로젝트는 회원가입, 로그인, 마이페이지, 관리자 기능까지 **`user`** 테이블을 기준으로 구현이 완료된 상태이다.<br>
또한 DTO, Service, Repository, Mapper 등 서비스 전반이 해당 테이블과 연결되어 있어,<br> 
단순한 테이블명 변경이 아닌 구조 전반에 영향을 주는 수정이 필요한 상황이다.<br>

이러한 점을 고려하여 현 시점에서는 프로젝트의 안정적인 기능 완성을 우선으로 판단하였고,<br> 
**테이블명 변경 없이 user를 유지** 하기로 결정하였다.<br>

향후 리팩토링 단계에서는 **테이블명을 users 또는 member로 변경** 하고,<br> 
이에 따라 도메인, DTO, Repository, Mapper 등 관련 구조를 일관성 있게 수정할 예정이다.<br> 
이후 전체 기능 테스트를 통해 시스템 안정성을 검증할 계획이다.<br>

이를 통해 예약어 충돌 가능성을 줄이고, 도메인 명확성과 유지보수성을 개선하는 것을 목표로 한다.

## 업비트(Upbit) 자동매매 모듈 (2026.07)

`com.evcar.upbit` 패키지에 업비트 가상화폐 자동매매 기능이 추가되었다.

### 구성
- **시세 조회**: 업비트 공개 Quotation API (현재가/일봉/분봉, 마켓 목록, 인증 불필요)
- **전략**: 변동성 돌파(래리 윌리엄스), 이동평균 교차 — `TradingStrategy` 인터페이스로 확장 가능
- **종목 자동 선택** (`auto-select=true`, 기본): 후보 종목 차트를 스캔해 추세(MA20 상승)·RSI(과열 제외)
  필터를 통과하고 매수 신호가 뜬 종목을 자동 매수. 후보군은 메이저 코인 10종이 기본이며
  `upbit.trading.scanner.markets`를 비우면 거래대금 상위 종목을 자동 선정
- **모의투자(PAPER)**: 가상 잔고로 실시간 자동매매 시뮬레이션 (기본 모드, 수수료 0.05% 반영)
- **실거래(LIVE)**: JWT 인증 기반 시장가 주문 (`UPBIT_ACCESS_KEY`/`UPBIT_SECRET_KEY` 환경변수 필요)
- **백테스트**: 과거 일봉으로 전략 수익률/승률/최대낙폭 검증
- **대시보드**: `/trading` — 엔진 시작/정지, 잔고·손익, 백테스트 차트, 체결 내역

### 안전장치
- 기본 모드는 PAPER. `upbit.trading.mode=LIVE` 로 명시해야만 실주문 가능
- 1회 주문 상한(`max-order-krw`), 손절/익절(`stop-loss-pct`/`take-profit-pct`), 일일 손실 한도 초과 시 엔진 자동 정지
- 변동성 돌파 전략은 날짜(KST) 변경 시 보유분 자동 청산

### 실거래(LIVE) 운영 주의사항 — 업비트 API 정책
- **API 키 권한**: 자산 조회 + 주문 조회 + 주문하기만 부여. **출금 권한은 절대 부여 금지**
- **고정 IP**: 거래 API는 키 발급 시 등록한 공인 IP에서만 동작 (키당 최대 10개). 서버 IP가 바뀌면 주문 중단
- **키 유효기간**: 발급일로부터 1년, 연장 불가 → 만료 전 새 키로 교체 필요
- **요청 제한**: 주문 초당 8회, 시세 초당 10회 — 봇에 호출 스로틀 내장(150ms 간격). 429 초과가 반복되면 418 차단
- **자전거래(SMP)**: 같은 계정으로 수동 지정가 주문을 병행하면 `upbit.trading.smp-type=cancel_taker` 설정 권장
- **주문 재시도 금지**: 주문 API는 실패 시 자동 재시도하지 않음 (중복 주문 위험)

### 주의
가상화폐 투자는 원금 손실 위험이 크며 백테스트 수익률은 미래 수익을 보장하지 않는다.
실거래는 반드시 모의투자로 충분히 검증한 뒤 소액으로만 사용할 것.
API 키는 절대 저장소에 커밋하지 말고 환경변수로 주입한다.
본인 계좌 개인 사용 목적이며, 타인 자금 운용·신호 판매 등 서비스 제공은 자본시장법상 등록 대상이므로 금지.
